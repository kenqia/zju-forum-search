# Domain Docs

How the engineering skills should consume this repo's domain documentation.

- Read `CONTEXT.md` at the repository root before exploring.
- Read relevant ADRs under `docs/adr/`.
- Use the glossary vocabulary in issues, plans, tests, and implementation notes.
- Keep `CONTEXT.md` limited to domain language; keep implementation decisions in ADRs.

This repository uses a single-context layout:

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```
