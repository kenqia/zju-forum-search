# ADR-0001：采用查询时检索，不建立 CC98 全站本地索引

- 状态：已决定
- 日期：2026-09-05

## 背景

CC98 内容需要在校内网络或授权环境中访问。CC98 前端提示论坛内容仅限校内交流，未经允许禁止外传到公网；官方搜索接口还存在请求频率限制。全站历史内容的自动抓取和长期保存，既无法确认获得官方许可，也可能触发反爬和内容传播风险。

## 决策

第一版采用查询时检索：每次用户查询时，使用用户自己的 CC98 授权调用官方只读搜索接口，扩展出多个检索词，获取候选主题帖，再读取候选主题帖及其文字回帖并在本机完成重排。第一版不建立全站本地索引，不把帖子正文上传到第三方服务，也不提供公网共享内容库。

## 影响

- 优点：数据更接近实时；不需要保存全站副本；降低长期存储和内容传播风险。
- 限制：召回率受 CC98 官方关键词搜索接口限制；接口限速会增加响应时间；无法承诺覆盖所有历史帖子。
- 后续：若需要历史全量索引，先取得 CC98 管理方对访问频率、存储和使用范围的明确许可，再单独评估索引方案。
